**Goal:** Fix the date bug caused by mixing local and UTC dates, make CI catch mobile route type errors, stop the deploy workflows failing when secrets are missing, and remove a committed build artifact. These are the roadmap P0 items #1–#4 in `docs/superpowers/plans/2026-09-25-improvement-roadmap.md`.

**Architecture:** "Today" is always the user's **local** calendar date, formatted `yyyy-MM-dd` by `@sisigo/utils` (`today()`, `subtractDays()`, `formatDate()`). No code path may derive a calendar date from `Date.prototype.toISOString()`. Tests run under several timezones in CI so the bug can't come back.

**Tech Stack:** TypeScript, date-fns 4, vitest 3, Expo Router typed routes, GitHub Actions.

## Global Constraints

- Calendar dates are local dates in `yyyy-MM-dd`, produced only by `@sisigo/utils` helpers (`today`, `yesterday`, `formatDate`, `subtractDays`, `getLast30Days`).
- `toISOString()` is still fine for **timestamps** (`created_at`, `updated_at`, file names that carry a moment in time). Only calendar-date derivations change.
- `npm run type-check`, `npm run lint` (0 errors) and `npx turbo run test` must pass under `TZ=UTC`, `TZ=Pacific/Kiritimati` (UTC+14) and `TZ=Pacific/Pago_Pago` (UTC−11).

### Task 3: Deploy workflows skip cleanly without secrets + repo hygiene

**Files:**
- Modify: `.github/workflows/deploy-web.yml`, `.github/workflows/deploy-mobile.yml`
- Modify: `.gitignore`; untrack `apps/web/tsconfig.tsbuildinfo`; remove the empty dir `apps/web/lib/{supabase}`

**Context:** On every push, `Deploy web` fails in `next build` (Supabase URL/key missing while prerendering `/terms`), and `Deploy mobile` fails in `eas build` (no `EXPO_TOKEN`). Until the owner adds secrets, these jobs should **skip with a visible notice**, not fail. GitHub Actions can't use `secrets.*` in a job-level `if:`, so use a small gate job.

- [ ] **Step 1: Gate job pattern**

`deploy-web.yml`: add a first job
```yaml
  check-secrets:
    runs-on: ubuntu-latest
    outputs:
      ready: ${{ steps.check.outputs.ready }}
    steps:
      - id: check
        env:
          URL: ${{ secrets.NEXT_PUBLIC_SUPABASE_URL }}
          KEY: ${{ secrets.NEXT_PUBLIC_SUPABASE_ANON_KEY }}
        run: |
          if [ -n "$URL" ] && [ -n "$KEY" ]; then
            echo "ready=true" >> "$GITHUB_OUTPUT"
          else
            echo "ready=false" >> "$GITHUB_OUTPUT"
            echo "::notice title=Deploy web skipped::Set NEXT_PUBLIC_SUPABASE_URL and NEXT_PUBLIC_SUPABASE_ANON_KEY repository secrets to build and push the image."
          fi
```
and on `build-and-push`: `needs: check-secrets` and `if: needs.check-secrets.outputs.ready == 'true'`.
Apply the same pattern to `deploy-mobile.yml` with `EXPO_TOKEN` (notice title "Deploy mobile skipped"). Keep every existing trigger (push/tags/dispatch) unchanged.

Run `npx -y yaml-lint .github/workflows/*.yml`. Expected: success. If `actionlint` is available via `npx -y actionlint` or Docker (`docker run --rm -v "$PWD":/repo -w /repo rhysd/actionlint:latest`), run it too and fix any findings in the two edited files.
